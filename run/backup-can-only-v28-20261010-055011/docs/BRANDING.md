# free R-Net branding

The project includes a bundled **free R-Net** logo/icon set.

## Files

- `assets/branding/free-r-net-logo-1254.png`
- `assets/branding/free-r-net-icon-256.png`
- `assets/branding/free-r-net-icon-64.png`
- `assets/branding/free-r-net-icon-32.png`
- `assets/branding/free-r-net.ico`
- `docs/assets/free-r-net-logo-1254.png`
- `docs/assets/free-r-net-icon-64.png`

## Current use in the project

- `README.md` and `README.de.md` display the logo at the top
- `rollstuhl.emu` embeds the app icon via Qt resource file `rollstuhl.emu/resources.qrc`
- the emulator GUI shows the free R-Net logo in the header
- `ANWENDUNG.txt` references the bundled branding files

## Notes

The logo shows a stylized golden **R** with network nodes on a blue field.
The word **free** is intentionally highlighted in red.
